# Installing Hollow Knight 8-Player Co-op

Current public package: **v0.10.0**. Target game: **Hollow Knight 1.5.78.11833** with the matching Modding API.

## Manual installation

1. Install the matching Hollow Knight Modding API.
2. Download [HollowKnightLocal8-v0.10.0.zip](https://github.com/RaulSB-code/HollowKnight-Local8/releases/download/v0.10.0/HollowKnightLocal8-v0.10.0.zip).
3. Close the game. Extract the ZIP into `Mods/HollowKnightLocal8/`, so that the installed file is `Mods/HollowKnightLocal8/HollowKnightLocal8.dll`.
4. Replace the previous DLL. Remove duplicate copies from other mod folders.
5. Start the game. The mod list must show **Hollow Knight 8-Player Co-op 0.10.0**.
6. Load a save and use **F8**, or your configured panel key. Press Start on another controller to join.

There are no additional installation assets: artwork and translations are embedded. Existing technical filenames, settings and save identifiers are retained.

## Lumafly

Once the ModLinks entry is accepted and updated, search for **Hollow Knight 8-Player Co-op** and install/update it through Lumafly. The ModLinks version is **0.10.0.0**.

## Optional companion mods

- **Custom Knight**: individual skins and easier player identification.
- **Enemy HP Bar**: readable shared enemy/boss health.

Neither is required. See [compatibility](COMPATIBILITY.md) before using large content mods.
