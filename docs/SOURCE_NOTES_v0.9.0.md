# v0.9.0 source notes

The source for v0.9.0 was recovered from the exact build 139 assembly used for the public release.

A complete hand-written C# tree matching that final binary was not preserved because some late development changes were applied directly at IL/binary level. The recovered source therefore does not preserve the original formatting or all original local variable names.

Before publication, the recovered package was cleaned: the reference release DLL, local paths and decompiler diagnostic comments were removed, and project references were converted to local build properties.

This distinction is documented intentionally. The v0.9.0 GitHub Release is the authoritative binary for that version.
