# Hollow Knight Local8

Local multiplayer mod for **Hollow Knight** focused on supporting **2–8 players on the same PC**.

> **Status:** private alpha / work in progress.  
> Local8 is **not yet published on Lumafly or ModLinks**.

## Project goals

Local8 is being developed to make Hollow Knight playable locally with more than two players while keeping the original game as intact as possible.

Main goals include:

- 2–8 local players.
- Independent player health, Soul and input.
- Shared world and progression.
- Multiplayer-aware interactions and transitions.
- Cooperative camera and teleport safeguards.
- Controller and keyboard support.
- Revive and respawn systems designed for multiple players.
- Compatibility work for common Hollow Knight mods, including per-player skins where possible.
- Configuration options for multiplayer behaviour.

## Development status

The mod is currently under active alpha development. Systems may change between test builds and some areas of the game can still require special multiplayer handling.

Public installation instructions will be added when a stable release is ready.

## Bug reports

When reporting a problem, please include:

1. Local8 build/version (for example `alphaXX`).
2. Hollow Knight game version.
3. Number of active players.
4. Other enabled mods.
5. Area/scene where the issue happened.
6. Steps to reproduce the problem.
7. The Local8 log if available.
8. Screenshots or video when they help explain the issue.

## Releases

When Local8 is ready for public distribution, stable builds will be published through **GitHub Releases** and the project will be prepared for submission to **ModLinks/Lumafly**.

Test DLLs and development builds should not be treated as stable releases.
